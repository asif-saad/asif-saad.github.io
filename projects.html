MNIST Image Classification with Quantum Neural Networks

Quantum Machine Learning · PyTorch · Classiq SDK

Developed a hybrid quantum neural network workflow for handwritten-digit classification. The project combines classical deep-learning tools with quantum technology from Classiq to explore quantum-enhanced image classification.

The work investigates how quantum circuits can be integrated into a machine-learning pipeline, including data preparation, model design, training, and evaluation.

GitHub repository · Project notebook

Quantum Algorithms Learning Notebook

Quantum Computing · Variational Algorithms · Quantum Simulation

A learning-oriented notebook covering quantum data encoding, qubit mapping, variational quantum eigensolvers, and quantum phase estimation. The project documents concepts and implementations used to develop practical quantum-computing skills.

GitHub repository · Project notebook

Vehicle Detection in Urban Environments

Computer Vision · Object Detection · YOLO

Research and experimentation on evaluating YOLO architectures for vehicle detection in complex urban environments in Bangladesh. The project considers practical challenges such as varied traffic conditions, cluttered scenes, and visual complexity.
